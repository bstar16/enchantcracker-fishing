# Enchant Cracker + Fishing 1.4.2 (Forge 1.12.2)

Initial repository release of the existing **1.4.2** mod. The supplied JAR is unchanged; this repository adds a concise command guide and includes the existing source project.

- Reveal enchanting-table outcomes and target single or multiple enchantments.
- Calibrate player RNG and execute controlled item-drop plans.
- Automatically fish for a chosen item after one manual cast, stopping after confirmed pickup.
- Use fast or normal recasting; shallow and single-block pools are supported.

**Requirements:** Minecraft 1.12.2, Java 8, and Forge 14.23.5.2859. Put the mod JAR in the client's `mods` folder and remove older copies.

**Server compatibility:** enchanting manipulation requires vanilla per-player RNG. Targeted fishing was designed for the custom `paper-1.12.2-rng-transfer-fishing.jar` server build, which is not included. See the README for settings, commands, and usage.
